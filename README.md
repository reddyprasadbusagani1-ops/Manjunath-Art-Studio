
# Manjunath Art Studio 🎨

A bilingual artist portfolio website created to showcase traditional
Indian artwork and simplify customer enquiries.

## 🌐 Live Website

https://exact-screen-show-52.lovable.app

## ✨ Features

- Artwork gallery with categories and filters
- English and Telugu language support
- Individual artwork viewing
- Custom artwork enquiries
- WhatsApp integration
- Responsive interface for mobile and desktop

## 🛠️ Tools and Technologies

- Lovable — AI-assisted development
- React.js — UI components
- TypeScript — application development

## 📌 Project Type

Frontend-focused web development project.

## 🎯 Objective

To help an artist showcase handmade artwork online and make it easier
for customers to enquire about existing and custom creations.

## 🚀 Future Improvements

- Database integration
- Secure artwork image storage
- Admin dashboard for artwork management
